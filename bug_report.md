# Баг-репорт BUG-001

**Заголовок:** Бесплатная доставка не применяется при сумме заказа ровно 10000 тенге (обе зоны)

**Окружение:** Python 3.13.18, pytest 9.1.1, модуль shop.py (учебный), ОС Linux

**Шаги воспроизведения:**
1. Из папки проекта запустить `python -m pytest -v --tb=short`.
2. Либо вызвать `delivery_cost(10000, "city")` и `delivery_cost(10000, "region")`.

**Входные данные:** amount = 10000; zone = "city" и "region"

**Ожидаемый результат:** доставка 0 (требование: от 10000 включительно доставка бесплатна)

**Фактический результат:** city -> 1000, region -> 2000 (итого total 11000 и 12000)

**Падающие тесты:** test_delivery[10000-city-0], test_delivery[10000-region-0] (см. before_fix_output.txt)

**Причина:** в delivery_cost условие `if amount > 10000` исключает границу; нужно `>=`.

**Серьёзность:** Major. Клиент переплачивает за доставку на граничной сумме, функциональность не ломается и обходного пути нет, но дефект затрагивает деньги. Не Critical: сбоя системы нет.

**Исправление:** `if amount > 10000:` -> `if amount >= 10000:`
